## 一间可以慢慢生长的个人书房

未尽是面向单个使用者、本地部署的文学文化 Agent 工作台。它将开放全文与书目元数据、混合检索、人格卡、长短期记忆和文化书架连接起来，让作品讨论能够回到原文，也让用户能查看和管理 Agent 记住了什么。

## 从文本到证据

文档经过解析、清洗和 L1/L2/L3 三级分块，保留页码、层级和父子块关系。检索使用 BGE-M3 向量与 Milvus BM25 稀疏索引，通过 RRF 融合，再按需合并父块上下文；支持可选重排、查询改写和证据不足时的澄清。

作品事实、系统解读与陪伴式表达各有边界。作品讨论可以查看引文与检索轨迹，日常问候则不必每次触发书库检索。

## 人格与记忆由用户掌握

人格卡包含身份、声音、价值观和行为边界，可版本化、比较与恢复。模型和规则先生成候选记忆，经用户确认后才进入长期记忆；记忆保留来源，支持作用域、过期、替代、撤销与删除。

上下文按人格、重点记忆、摘要、近期消息、相关记忆与 RAG 证据装配，并控制 token 预算。SQLite FTS 与向量召回共同服务长期记忆，异步向量化减少对聊天响应的阻塞。

## 工程实现

- FastAPI 提供 API、SSE 流式对话与资源管理；浏览器工作台使用 HTML、CSS 和 JavaScript。
- Docker Compose 编排 API、Worker、Milvus、Embedding 与存储依赖。
- 提供健康检查、脱敏日志、备份校验与隔离恢复预演。
- 可选音乐连接器为个人书房补充只读文化入口，资料进入模型、记忆与主动回声分别授权。

## 当前阶段

项目处于单用户、本地优先的可运行技术内测阶段。多轮对话自然度、文学讨论路由与跨日记忆体验仍在持续校准；不将工程测试通过等同于长期体验成熟。

没有模型 Key 时，入库、检索与本地治理仍可使用，生成步骤会明确降级。公开仓库不包含个人书籍正文、数据库、授权信息与私有评测记录，也不提供公网多用户服务。
